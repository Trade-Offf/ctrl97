# 设计规范

视觉概念是 Calm Control / 安静的个人控制台。页面像一张收拾过的工作台：信息找得到，控制感来自对齐和留白，不来自发光和噪音。

阶段 2 实现本文件。阶段 0 不写组件。

## 关键词

克制、清晰、精确、温和、工程感、生活感、内容优先、轻量交互。

工程感体现在网格、等宽元信息和准确的状态。生活感体现在暖中性色、可读的正文和不过度的装饰。二者都服从内容。

## 不要使用的视觉

- 紫蓝 AI 渐变
- 霓虹光效
- 代码雨
- 赛博朋克
- 故障字体
- 粒子背景
- 旋转地球
- 过度玻璃拟态
- 复杂 3D
- 模板化 SaaS 首页
- 满屏终端装饰

网站可以有技术感，但不扮演黑客。不使用玻璃模糊叠层、彩色光晕、渐变按钮和大幅装饰插画。

## 颜色

颜色以 CSS 变量保存。浅色是默认值，深色在 `[data-theme="dark"]` 中覆盖。阶段 2 把变量映射进 Tailwind，不另建一套色值。

### 浅色

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--background` | `#F7F7F5` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片、顶栏、弹出层 |
| `--text` | `#171717` | 正文和标题 |
| `--muted` | `#737373` | 仅白底上的辅助信息 |
| `--muted-strong` | `#5E5E5C` | 背景上的次要文字 |
| `--border` | `#E5E5E2` | 分隔线和卡片边框 |
| `--accent` | `#22A06B` | 状态点、强调线、实心按钮底 |
| `--accent-text` | `#146C48` | 链接、焦点环 |
| `--experimental` | `#FF6B35` | 「试验」状态标记 |

### 深色

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--background` | `#111110` | 页面背景 |
| `--surface` | `#191918` | 卡片、顶栏、弹出层 |
| `--text` | `#F1F1EF` | 正文和标题 |
| `--muted` | `#A3A3A0` | 次要文字 |
| `--muted-strong` | `#A3A3A0` | 与 `--muted` 相同，深色已满足对比度 |
| `--border` | `#2C2C2A` | 分隔线和卡片边框 |
| `--accent` | `#45C28A` | 链接、状态点、强调线、实心按钮底 |
| `--accent-text` | `#45C28A` | 与 `--accent` 相同 |
| `--experimental` | `#FF8F66` | 「试验」状态标记 |

深色试验色是本规范补上的。浅色 `#FF6B35` 在深色背景上可以辨认，但 `#FF8F66` 更清晰，并且只用于标记，不铺成大面积背景。

### 对比度

目标是 WCAG 2.2 AA。下列比值在阶段 0 按相对亮度计算，阶段 2 实现后用实际像素再核对一次。

| 组合 | 比值 | 结论 |
| --- | --- | --- |
| `#171717` on `#F7F7F5` | 16.71:1 | 正文 |
| `#737373` on `#FFFFFF` | 4.74:1 | 可用于白底辅助文字 |
| `#737373` on `#F7F7F5` | 4.42:1 | 不用于文字 |
| `#5E5E5C` on `#F7F7F5` | 6.06:1 | 背景上的次要文字 |
| `#22A06B` on `#F7F7F5` | 3.10:1 | 非文字标记，不作小字 |
| `#146C48` on `#F7F7F5` | 5.99:1 | 浅色链接 |
| `#146C48` on `#FFFFFF` | 6.43:1 | 浅色链接 |
| `#171717` on `#22A06B` | 5.39:1 | 浅色实心按钮的文字 |
| `#F1F1EF` on `#111110` | 16.71:1 | 深色正文 |
| `#A3A3A0` on `#111110` | 7.47:1 | 深色次要文字 |
| `#45C28A` on `#111110` | 8.40:1 | 深色链接 |
| `#111110` on `#45C28A` | 8.40:1 | 深色实心按钮的文字 |
| `#FF6B35` on `#F7F7F5` | 2.64:1 | 不作文字 |
| `#FF8F66` on `#111110` | 8.43:1 | 可作标记；正文仍用 `--text` |

使用规则：

- 链接使用 `--accent-text`，悬停时加下划线。不把 `#22A06B` 当作浅色小字。
- 实心按钮的文字在浅色主题用 `#171717`，在深色主题用 `#111110`。不在品牌绿上放白字。
- 焦点环使用 `--accent-text`，2px 实线，偏移 2px。浅色品牌绿只勉强达到非文字对比的 3:1，不用它做焦点环。
- 「试验」用小圆点或 2px 短线配合文字标签。标签颜色是 `--text`。
- 状态不只靠颜色。已上线、构建中、试验、暂停、归档都有文字。
- 不使用渐变、发光阴影和彩色背景块。

## 字体

| 角色 | 字体 | 用途 |
| --- | --- | --- |
| 界面 | IBM Plex Sans | 导航、按钮、作品列表、界面正文 |
| 笔记正文 | Source Serif 4 | Notes 详情的长文 |
| 等宽 | IBM Plex Mono | 日期、状态、键盘按键、代码 |

阶段 2 通过 Fontsource 自托管，并做子集。不从第三方字体 CDN 加载。

后备字体：

- 界面：`IBM Plex Sans, ui-sans-serif, system-ui, sans-serif`
- 笔记：`Source Serif 4, ui-serif, Georgia, serif`
- 等宽：`IBM Plex Mono, ui-monospace, SFMono-Regular, Menlo, monospace`

不使用 Geist，避免做成常见的 AI 产品模板。不使用故障字体、像素字体和手写体。

### 字号

基准是 16px。只使用下面的级数：

| 名称 | 字号 / 行高 | 用途 |
| --- | --- | --- |
| meta | 12 / 16 | 日期、状态。使用等宽字体 |
| small | 14 / 20 | 辅助说明、标签 |
| body | 16 / 26 | 界面正文 |
| prose | 18 / 30 | 笔记正文 |
| title | 20 / 28 | 卡片标题 |
| section | 28 / 36 | 栏目标题 |
| page | 40 / 48 | 页面标题 |
| display | 56 / 64 | 仅首页品牌名，全站最多一次 |

标题使用界面字体，字距保持默认，不拉大、不压缩。笔记正文使用衬线字体。中文和英文共用同一套字号，不为英文单独放大标题。

## 间距与宽度

间距以 4px 为基数：4、8、12、16、24、32、48、64、96。

- 页面左右内边距：小屏 20px，宽屏 32px。
- 笔记与 About、Now 的正文最大宽度 40rem。
- 作品列表最大宽度 70rem，即 1120px。
- 段落之间用 16px 或 24px。栏目之间用 48px 或 64px。
- 相关元素靠拢，不相关元素分开。不使用均匀铺满的卡片墙来制造丰富感。

## 圆角、边框与阴影

- 控件、输入框和按键：6px。
- 卡片和图片：10px。
- 状态点：圆形。
- 不使用 16px 以上的大圆角。
- 分隔使用 1px `--border`。
- 不使用投影营造层次。弹出层若必须与背景分离，只用 1px 边框和 `--surface`。

## 动效

交互反馈时长 160ms，缓动 `cubic-bezier(0.2, 0, 0, 1)`。只过渡颜色、背景色、边框色和透明度。

不使用视差、滚动劫持、循环背景、弹跳和位移装饰。`prefers-reduced-motion: reduce` 时关闭过渡。

主题切换的交叉淡化属于阶段 5。阶段 2 只提供两套颜色变量，并跟随系统的 `prefers-color-scheme`。

## 布局语气

顶栏包含文字标志 Ctrl97、栏目导航和语言切换。标志链回当前语言的首页，可访问名称是 Ctrl97。

导航文案：

- 中文：作品、笔记、现在、关于
- 英文：Works、Notes、Now、About

页脚只放品牌句和已经确认的链接。没有社交链接时，页脚不出现一排空图标。

图标只用 Lucide，以静态 SVG 引入，描边 1.5，尺寸 16 或 20，颜色跟随文字。图标不单独承担含义，旁边有文字，或有可访问名称。

作品卡片是一条清楚的记录：名称、一句摘要、状态、年份。不是带大图的营销卡片。没有封面时不生成装饰图。

## 空状态

空状态是正常页面，不是错误。文案使用 [CONTENT.md](CONTENT.md) 里已批准的句子，居左排列，不放插画。

## 主题切换之前

阶段 2 用 CSS 跟随系统外观。手动切换、记住选择和防闪烁脚本留到阶段 5。两套色值在阶段 2 就要可用，避免日后补深色时改结构。
