> GPT4 每月 20 刀，Github Copilot 每月 10 刀


首先叠个甲：**免费不是 0 成本**。

由于我在日常开发过程中，Copilot 对我来说是必需品，我会用它检查代码、写工具函数、写注释、干苦力。所以这钱是我的必要支出。而这篇文章是介绍**如何基于 Copilot token 调用 GPT4 服务**的，没有二次成本，不用每月再额外花 20 刀买 GPT4 服务，所以描述为免费。

如果大家有 0 成本使用的方法欢迎在评论区发出来，供朋友们学习尝试，欢迎一起讨论；

### 第三步：获取 Copilot CLI token

获取你自己 Github 账号的 Copilot Plugin Token ，目前有两种方式：

*   通过 Python 脚本获取，只需要 requests 库
*   通过安装[ Github Copilot CLI ](https://githubnext.com/projects/copilot-cli/)授权获取（**推荐，我用这个**）


```bash
# 该脚本会自动安装 Github Copilot CLI 并通过授权获取 Github Copilot Plugin Token
bash -c "$(curl -fsSL https://raw.githubusercontent.com/aaamoon/copilot-gpt4-service/master/shells/get_copilot_token.sh)"
```

![image.png](/notes-media/7329433979806908450/7422fb2355581999.png)

#### 遇到问题：无权限

![image.png](/notes-media/7329433979806908450/428bf4654a6feec6.png)

**原因** ：需要用已授权 Copilot 的 token 登录账号，这里建议安装 **GitHub CLI**

```bash
brew install gh    # 安装 GitHub CLI

gh auth login 	# 登录账号
gh auth logout	# 登出账号
gh auth status     # 查看账号状态
```

![截屏2024-01-29 19.38.07.png](/notes-media/7329433979806908450/2a538a25efd28486.png)

#### Github 如何创建 token

1、访问 [GitHub 设置](https://github.com/settings/profile)  

2、依次选择 Developer settings -> Personal access tokens -> Fine-grained tokens  

3、点击 **Generate new token** 创建新令牌

![image.png](/notes-media/7329433979806908450/d923a08511e76d8c.png)

![image.png](/notes-media/7329433979806908450/56bcb307c8f4cee7.png)

4、然后重新执行命令自动安装 Github Copilot CLI

![image.png](/notes-media/7329433979806908450/9ae723042566db87.png)

5、进入上图中说明的授权网站：<https://github.com/login/device>，输入被灰块遮挡的 8 位验证码

![image.png](/notes-media/7329433979806908450/aacabcaf5d840c1c.png)

6、可能会因网络问题失败，多试几次就有了，如下图灰块遮盖内容，就是你的 **Copilot CLI token**


![image.png](/notes-media/7329433979806908450/31c5b34309d2d21e.png)


### 第四步：安装 ChatGPT-Next-Web

![image.png](/notes-media/7329433979806908450/c80e1ecf6e38dd5a.png)

安装地址：<https://github.com/ChatGPTNextWeb/ChatGPT-Next-Web/releases>
同时需要配置一些参数，如图，
- **接口地址**使用 copilot-gpt4-service 运行后的 Service，通常是 http://127.0.0.1:8080
- **API Key** 使用经过上述请求方法获得的 Copilot CLI token
- **模型**要记得切换成 gpt-4，因为默认使用 3.5

### 第五步：运行 copilot-gpt4-service

进入 copilot-gpt4-service 文件夹，执行：`go run .`

![截屏2024-01-30 18.58.03.png](/notes-media/7329433979806908450/499495565ba10671.png)

前四步都是一次性的，只要你配置过一次之后直接执行第五步就好了。  

> token 会过期，可能 90 天后需重新走一次授权流程，后续使用可以关注一下
