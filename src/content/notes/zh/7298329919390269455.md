### 场景描述
当鼠标移到卡片上，svg 格式的 icon 颜色可以变化

![ainimation.gif](/notes-media/7298329919390269455/eae7f01d22fa65f1.gif)
这个需求实现方式有很多，最基本的可以通过监听鼠标移入/移出事件，准备两套图片，根据状态切换：

```jsx
import React, { useState } from 'react';

const [imgSrc,setImgSrc] = useState();

var example = document.getElementById("example");
example.addEventListener("mouseover", function(){
    console.log("鼠标移入了元素");
    setImgSrc(iconLight) // 更新图片src为亮色图
});
example.addEventListener("mouseout", function(){
    console.log("鼠标移出了元素");
    setImgSrc(iconDark) // 更新图片src为暗色图
});
```

但挺麻烦，如果容器中每个item的图片都不一样，那图片一共要准备 2N 张，以及大量的状态切换会让代码脏乱。

### 进阶偷懒

**我不想整这么多图，也不想搞这么多状态！**

能不能直接给 icon 改个色直接用就行呢？

可以，用.SVG格式图片（因为我写的是个内部工具小需求，自由度比较高，以下描述的方法仅适合纯色icon）

可以看到 `path` 标签里有一个属性叫 `fill` ，这个值决定了 icon 的颜色。

如果用网站自带的颜色选择器，选了颜色后再复制 SVG 代码就会得到带 fill 属性的内容。

但这个内联属性（优先级高）覆盖了我们通过 `className` 赋予的颜色样式。

所以要删掉，然后用 css 伪类 :hover 实现颜色变化。

```scss
}
```

#### 方法二：引入 svg 图片，修改 drop-shadow

方法一会导致代码里出现大量的 svg 标签，又会导致代码脏乱。能更简单一点吗？

可以，不过要用奇技淫巧：`CSS3 滤镜 filter 中的 drop-shadow` **：** [**https://developer.mozilla.org/zh-CN/docs/Web/CSS/filter-function/drop-shadow**](https://developer.mozilla.org/zh-CN/docs/Web/CSS/filter-function/drop-shadow)

![截屏2023-11-07 14.38.07.png](/notes-media/7298329919390269455/0d3aa1321b777ede.png)
下载svg图片到本地，然后 import 引入。通过 filter: drop-shadow 修改投影颜色改变 icon 颜色

```jsx
import logo from './logo.svg';

<img
  className="logo"
  style={{ transform: 'translate(-100px)' }}
  src={logo}
/>
```

```scss
.item {
  overflow: hidden;  // 超出父级范围裁掉，隐藏投影
}
.logo {
  width: 30px;
  height: 30px;
  filter: drop-shadow(100px 0 0 #249ffd);
}

.logo:hover {
  width: 30px;
  height: 30px;
  filter: drop-shadow(100px 0 0 #ffffff);
}
```

为什么说是奇技淫巧呢？归根到底还是兼容性的问题，需要根据你的具体业务，合理使用技巧。
